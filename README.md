# Lampa plugins

Плагины для [Lampa](https://github.com/yumata/lampa-source) с автообновлением. Ссылка добавляется в Лампу один раз и больше не меняется.

## Установка

1. В Лампе откройте **Настройки → Расширения → Добавить плагин**.
2. Вставьте ссылку и нажмите OK:

   ```
   https://snowymay111.github.io/lampa-plugins/loader.js
   ```

3. Перезапустите Лампу.

Если раньше плагины ставились по другим ссылкам (например, `cdn.jsdelivr.net/gh/SnowyMay111/lampa-torrserver-failover@v1.0.0/...`), удалите их: в списке расширений удерживайте OK на плагине или нажмите OK дважды. Иначе старая версия загрузится раньше новой.

## Как работает автообновление

При каждом запуске Лампы загрузчик читает [manifest.json](manifest.json) и подключает все включённые плагины из списка. Когда в списке меняется версия плагина или появляется новый, после перезапуска Лампы они подхватываются сами, а в Лампе появляется уведомление «Плагины обновлены». Если интернета нет, используется последний удачно загруженный список.

## Плагины

| Плагин | Что делает |
| --- | --- |
| `torrserver_failover` | Если основная ссылка на TorrServer не отвечает, включает дополнительную и возвращается на основную, когда она оживёт. Переключатель и статус серверов добавляются в Настройки → TorrServer. |
