# Lampa plugins

Плагины для [Lampa](https://github.com/yumata/lampa-source) с автообновлением. Ссылка добавляется в Лампу один раз и больше не меняется.

## Установка

1. В Лампе откройте **Настройки → Расширения → Добавить плагин**.
2. Вставьте ссылку и нажмите OK:

   ```
   https://snowymay111.github.io/lampa-plugins/loader.js
   ```

3. Перезапустите Лампу.

Если раньше плагины ставились по другим ссылкам (например, `cdn.jsdelivr.net/gh/SnowyMay111/lampa-torrserver-failover@v1.0.0/...`), удалите их: в списке расширений удерживайте OK на плагине или нажмите OK дважды. Старая ссылка с версией `@v1.0.0` зафиксирована навсегда и обновляться не может. Если оставить её, будет работать только старая версия.

## Как работает автообновление

При каждом запуске Лампы загрузчик читает [manifest.json](manifest.json) и подключает все включённые плагины из списка. Когда в списке меняется версия плагина или появляется новый, после перезапуска Лампы они подхватываются сами, а в Лампе появляется уведомление «Плагины обновлены». Если интернета нет, используется последний удачно загруженный список.

## Плагины

| Плагин | Что делает |
| --- | --- |
| `lampa_watch` | Один файл с двумя модулями, собирается командой `node build.js` из `src/`. |

### Модуль «Лучшая раздача»

На карточке фильма или сериала рядом с «Смотреть» появляется кнопка **«Лучшая раздача»**.

- **Пожелания.** Качество (до 4K), HDR, Dolby Vision, язык озвучки (русский, украинский, английский и другие, либо оригинал фильма), тип озвучки, субтитры, минимум раздающих. Для сериалов ещё сезон и серия. Пожелания запоминаются.
- **Подбор.** Плагин ищет раздачи через выбранный в Лампе парсер и считает баллы за качество, HDR, язык, сезон, число раздающих и надёжность трекера. Если чего-то не нашлось, берётся лучшее из оставшегося и показывается, чего именно не хватило. Заведомо плохое (камрип, 3D, чужой фильм или год) отсеивается.
- **Прогноз «будет ли лагать».** Сначала оценка по размеру раздачи, длине фильма, числу раздающих и вашей скорости. Потом реальный замер на TorrServer: он качает начало файла, и плагин смотрит скорость. Вердикт: плавно, на грани, будет лагать, не рекомендую. Если скорости не хватает, плагин даёт советы и предлагает раздачу полегче.
- **Запуск.** Открывает торрент в Лампе, сам выбирает нужный файл (самый большой для фильма, нужную серию для сериала) и запускает плеер.

### Модуль «Резервный TorrServer»

Если основная ссылка на TorrServer не отвечает, включает дополнительную и возвращается на основную, когда она оживёт. Переключатель и статус серверов добавляются в **Настройки → TorrServer**. Это тот же код, что был в отдельном плагине `torrserver_failover` версии 1.0.0.

## Разработка

```
node build.js                      # собрать plugins/lampa_watch.js из src/
node test/logic.test.js            # разбор названий, баллы, прогноз скорости
NODE_PATH=<где лежат jsdom и jquery@3> node test/ui.test.js   # интерфейс на макете Лампы
```

После изменения `src/` обязательно пересобрать бандл и поднять версию в `manifest.json`, иначе Лампа не увидит обновление.
